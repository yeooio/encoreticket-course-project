# 电影票务系统课程设计准备记录

## 作业依据
课程要求两人均编写代码；以小组提交课程报告 PDF、源码及运行环境说明，并准备演示答辩。正文约 30 页，使用课程报告模板；报告说明 Spring Boot 配置、三层协作、MyBatis-Plus、Bean、数据库逐表结构、依赖版本与项目结构。权限、事务、分页、定时任务可作为加分内容。模板保留指定空白页。

## 拟定题目与分工安排
拟题：基于 Spring Boot 的电影票务系统设计与实现。具体安排见《CYS需看_两人分工.md》。
- 朱佳燕（组长）：总体架构、数据库、选座订单、模拟支付、票券与退票，以及系统整合和报告统稿。
- CYS：用户账户、影片与场次展示、个人资料和密码修改，亲自参与相关代码完善，负责对应测试、截图和报告内容。

JDK 21、Spring Boot 4.1.1、MyBatis-Plus 3.5.17、MySQL 8.4、Redis、Flyway；支付为模拟渠道，非真实资金。三层主要为 Controller → Service → Mapper；部分复杂持久化通过 Repository 协作。具体服务器及依赖版本应以最终交付运行环境为准。
