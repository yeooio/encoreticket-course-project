# 电影票务系统课程设计两人分工

项目地址：https://github.com/yeooio/encoreticket-course-project

## 朱佳燕（组长）

- 负责项目统筹、总体架构、数据库设计与系统整合。
- 负责选座、订单、模拟支付、票券和退票的代码梳理、完善及演示。
- 负责报告的总体设计、数据库与购票业务部分，以及最终材料汇总。

## CYS（组员）

- 负责用户注册与登录、影片与场次展示、个人资料和密码修改相关功能。
- 阅读并理解上述功能的前端页面、接口和对应后端代码；亲自参与相关代码的完善或修改，记录自己实际完成的代码工作。
- 测试上述功能，记录操作步骤、结果并整理截图；编写报告中对应的功能实现和测试内容。
- 准备答辩：能操作并演示负责的功能，找到相关代码，说明页面如何调用接口以及后端如何处理。

## 共同完成

一起运行和检查系统，演示影片查询、选座下单、模拟支付、票券查询和退票的完整流程，互相了解对方模块并核对最终报告。

本分工为后续工作安排。已有代码应先阅读和理解；报告中的实际分工按两人真实完成的工作填写，不将既有代码直接写成组员新完成的工作。
